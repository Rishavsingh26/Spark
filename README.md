# Spark

A general knowledge reference app for Android. Displays Q&A data on countries, books, inventions, and more.

## Categories
- Country and Their Parliament
- Country and Their Capital
- Country and Their National Anthems
- Production and Their Revolutions
- Books and Their Authors
- Invention and Their Inventors

## Features
- Offline Q&A from bundled JSON
- Online fetch from remote backend
- Scrollable text view display

## Build
Eclipse/ADT project. Min SDK 12, Target SDK 27.
